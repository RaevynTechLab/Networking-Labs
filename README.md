
# 🌐 Networking Labs

Welcome to my networking lab portfolio!

I'm using this repository to document my hands-on learning as I explore computer networking, network infrastructure, configuration and troubleshooting.

My goal is to understand not just how networks work. But why they work the way they do and what happens when they don't. Because let's be real, troubleshooting is where things get interesting. 😂

## 🎯 Purpose

Build practical networking skills by designing, configuring, securing and troubleshooting network environments.

## 🛠️ Planned Lab Areas

- Network Fundamentals and the OSI Model
- IPv4 and IPv6 Addressing
- Subnetting and IP Address Planning
- Switching, VLANs and Trunking
- Routing and Network Connectivity
- Network Security and Access Control Lists
- DHCP, DNS and NAT
- Network Troubleshooting and Verification

## 💻 Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS
- Networking Commands and Utilities
- Wireshark (planned)

## 📂 Projects

Projects will be added as I complete them.

Each project will include:
- The objective and network requirements
- Network topology and IP addressing
- Configuration steps and commands
- Testing and verification
- Troubleshooting and lessons learned
